Petrify

Obsidian 플러그인

손글씨 노트 파일을 검색할 수 있는 Obsidian 문서로 바꾸는 Obsidian 플러그인이다.

  • 문제: 손글씨 노트와 키보드로 쓴 노트는 서로 다른 곳에 저장된다. 손글씨를 PDF로 내보내면 Obsidian의 검색, 링크, 태그를 쓸 수 없다.
  • 해결: Petrify는 손글씨를 Excalidraw 파일이나 Markdown 파일로 바꾼다. Petrify는 OCR(광학 문자 인식)로 글자를 읽어 검색할 수 있게 한다.

주요 기능

  • 지원 파일: Petrify는 Viwoods .note, Supernote X 시리즈 .note, PDF 파일을 읽는다.
  • Excalidraw 출력: Excalidraw 형식은 손글씨를 캔버스에 그대로 둔다. 사용자는 그 위에 글, 화살표, 강조, 링크를 더한다.
  • OCR: Tesseract.js는 기기 안에서 글자를 읽는다. Google Cloud Vision은 Google API로 글자를 읽는다.
  • 폴더 감시: Petrify는 로컬 폴더나 Google Drive 폴더를 감시한다. Petrify는 새 파일과 바뀐 파일을 자동으로 변환한다.
  • 끌어다 놓기: 사용자가 파일 탐색기에 손글씨 파일을 놓으면, Petrify는 그 위치에 변환 결과를 만든다.
  • 중복 방지: Petrify는 파일과 페이지의 해시를 비교해서 이미 변환한 파일을 건너뛴다.
