claude-mermaid-view

Claude Code mod

A Claude Code mod that draws the mermaid blocks in Claude's replies as text diagrams in the terminal.

  • Problem: When you move an ASCII diagram from Claude into docs, PRs or Slack, its alignment breaks. You can move mermaid source anywhere. But the terminal shows mermaid source only as code.
  • Solution: The mod keeps the source as mermaid and draws it as a diagram only on the terminal screen.

Features

  • Diagram types: The mod draws flowchart, sequence, class, ER, state and xychart diagrams.
  • Fit to width: When a diagram is wider than the terminal, the mod draws it again with less spacing or wrapped labels.
  • Wide characters: The mod aligns Korean, Chinese, Japanese and emoji labels to the width that they use in the terminal.
  • Source tools: Each diagram has buttons to show the source, copy the source and open it in mermaid.live.
  • Mermaid prompt: The mod tells Claude to draw mermaid blocks instead of ASCII art. You turn this on and off with /mermaid-prompt.
  • Source kept: The mod changes only the display. The saved message keeps the mermaid source.
