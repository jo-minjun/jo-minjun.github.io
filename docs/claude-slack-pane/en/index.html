claude-slack-pane

Claude Code mod

A Claude Code mod that puts Slack in a pane beside the conversation.

  • Problem: To show a Slack conversation to Claude, you open the Slack app, copy the messages, go back to the terminal and paste them. For a long thread, you do this many times.
  • Solution: The mod shows Slack channels and threads in the terminal. You quote a message or a whole thread into your next prompt with one button.

Features

  • Two columns: The left column shows the channels, private channels, DMs and group DMs you are in, plus message search. The right column shows the open channel or thread.
  • Search: Search supports Slack search modifiers such as in:, from: and after:. From me finds only your own messages.
  • Live view: The mod reads only the open channel or thread again, every 10 seconds by default. You change the interval to 5–300 seconds with /slack-pane-refresh.
  • Send messages: The line above the input shows where a message goes (To #general, Reply in thread · #general).
  • Send images: You attach an image by its file path, or paste the image on the clipboard. Clipboard paste works only on macOS.
  • Quote into Claude: Quote message or Quote thread puts a short reference in the prompt box. When you send the prompt, the mod attaches the message or the whole thread as context. The mod marks quoted text as untrusted data.
  • No token of its own: The mod talks to Slack through the Slack MCP server you already connected to Claude Code. It needs no Slack app and no token of its own.

Details

Install
/plugin install slack-pane --marketplace jo-minjun/claude-slack-pane
Requires
Claude Code 2.1.316 or later, Slack MCP server connected
Built with
TypeScript, Slack MCP
