claude-slack-pane

Claude Code mod

Claude Code 대화 옆 패널에 Slack을 띄우는 Claude Code mod다.

  • 문제: Slack 대화를 Claude에게 보여 주려면 Slack 앱을 열고, 메시지를 복사하고, 터미널로 돌아와 붙여 넣어야 한다. 스레드가 길면 이 작업을 여러 번 반복한다.
  • 해결: 이 mod는 터미널 안에서 Slack 채널과 스레드를 보여 준다. 사용자는 메시지나 스레드 전체를 버튼 하나로 다음 프롬프트에 인용한다.

주요 기능

  • 두 열 화면: 왼쪽 열은 사용자가 속한 채널, 비공개 채널, DM, 그룹 DM과 메시지 검색을 보여 준다. 오른쪽 열은 연 채널이나 스레드를 보여 준다.
  • 검색: 검색은 in:, from:, after: 같은 Slack 검색 조건을 지원한다. From me는 내가 쓴 메시지만 찾는다.
  • 실시간 보기: mod는 연 채널이나 스레드만 기본 10초마다 다시 읽는다. 사용자는 /slack-pane-refresh로 간격을 5–300초 사이에서 바꾼다.
  • 메시지 보내기: 입력창 위 줄이 메시지가 갈 곳(To #general, Reply in thread · #general)을 보여 준다.
  • 이미지 보내기: 사용자는 파일 경로로 이미지를 첨부하거나, 클립보드의 이미지를 붙여 넣어 보낸다. 클립보드 붙여 넣기는 macOS에서만 된다.
  • Claude에 인용: Quote message나 Quote thread를 누르면 프롬프트 입력창에 짧은 참조가 들어간다. 프롬프트를 보내면 mod가 메시지나 스레드 전체를 맥락으로 붙인다. mod는 인용한 글을 신뢰하지 않는 데이터로 표시한다.
  • 별도 토큰 없음: mod는 Claude Code에 이미 연결한 Slack MCP 서버로 Slack과 통신한다. Slack 앱이나 별도 토큰은 필요 없다.
