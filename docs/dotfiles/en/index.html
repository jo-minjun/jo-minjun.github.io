dotfiles

Dev environment

A macOS development environment that chezmoi manages.

  • Problem: On each new Mac, you must set up development tools, apps, shell settings and AI agent settings again.
  • Solution: One install command applies all of these settings. chezmoi gets secrets and licenses from 1Password.

Features

  • Tools: Homebrew installs development, cloud and infrastructure, database and AI tools, and apps.
  • Runtime versions: mise installs the default versions of Node.js, Java, Python and Kotlin.
  • Shell and terminal: chezmoi sets up oh-my-zsh, Powerlevel10k and the Ghostty terminal.
  • Separate accounts: Under ~/Projects/work/, Git uses the work email. In the same folder, the GitHub CLI switches to the work account.
  • Work settings: Work accounts, infrastructure details and work skills are in the private repository dotfiles-work. In the last install step, chezmoi applies this repository as a separate chezmoi source. When chezmoi cannot access this repository, it skips this step.
  • AI agents: chezmoi manages Claude Code settings (LSP, statusline, permissions, subagents, skills) and Codex settings. Claude Code and Codex read the same global instruction file. chezmoi also installs Claude Code plugins, MCP servers, agent skills and graphify, a tool that builds a knowledge graph from code and documents.
  • macOS settings: chezmoi sets the key repeat speed, Dock auto-hide and a lock screen shortcut. chezmoi also applies the BetterTouchTool license and presets.
  • Touch ID for sudo: When you run sudo in the terminal, you authenticate with Touch ID.
