dotfiles

Dev environment

dotfiles is a macOS development environment that chezmoi manages. One install command applies CLI tools, apps, shell settings and AI agent settings to a new Mac. chezmoi gets secrets and licenses from 1Password. chezmoi applies work settings from a separate private repository.

Features

  • Tools: Homebrew installs development, cloud and infrastructure, database and AI tools, and apps.
  • Shell and terminal: chezmoi sets up oh-my-zsh, Powerlevel10k and the Ghostty terminal.
  • Separate accounts: Under ~/Projects/work/, Git uses the work email. In the same folder, the GitHub CLI switches to the work account.
  • AI agents: chezmoi manages Claude Code settings (LSP, statusline, permissions, subagents, skills) and agent skills.
  • Touch ID for sudo: When you run sudo in the terminal, you authenticate with Touch ID.
