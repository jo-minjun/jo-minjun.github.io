dotfiles

개발 환경 설정 · Dev environment

chezmoi로 관리하는 macOS 개발 환경 설정이에요. 명령 하나로 새 Mac에 CLI 도구, 앱, 셸 설정을 설치해요. 시크릿과 라이선스는 1Password에서 가져와요.

A macOS development environment managed with chezmoi. One command installs CLI tools, apps and shell settings on a new Mac. Secrets and licenses come from 1Password.
