개발 환경 설정

chezmoi로 관리하는 macOS 개발 환경 설정이다.

  • 문제: 새 Mac마다 개발 도구, 앱, 셸 설정, AI 에이전트 설정을 다시 맞춰야 한다.
  • 해결: 설치 명령 하나가 이 설정을 모두 적용한다. chezmoi는 시크릿과 라이선스를 1Password에서 가져온다. chezmoi는 업무 설정을 비공개 저장소에서 따로 적용한다.

주요 기능

  • 도구 설치: Homebrew가 개발, 클라우드·인프라, DB, AI 도구와 앱을 설치한다.
  • 셸과 터미널: chezmoi는 oh-my-zsh, Powerlevel10k, Ghostty 터미널을 설정한다.
  • 계정 분리: ~/Projects/work/ 아래에서는 Git이 회사 이메일을 쓴다. 같은 폴더 아래에서 GitHub CLI는 회사 계정으로 바뀐다.
  • AI 에이전트: chezmoi는 Claude Code 설정(LSP, statusline, 권한, 서브에이전트, 스킬)과 에이전트 스킬을 관리한다.
  • Touch ID sudo: 터미널에서 sudo를 실행하면 Touch ID로 인증한다.
