Petrify

Obsidian plugin

Petrify is an Obsidian plugin that converts handwritten note files into Obsidian notes. Handwritten notes and typed notes usually stay in different places. When you export handwriting as PDF, you cannot search, link or tag it in Obsidian. Petrify converts handwriting into Excalidraw or Markdown files. Petrify uses OCR (optical character recognition) to read the text, so you can search it.

Features

  • Supported files: Petrify reads Viwoods .note, Supernote X-series .note and PDF files.
  • Excalidraw output: The Excalidraw format keeps your handwriting on a canvas. You can add text, arrows, highlights and links on it.
  • OCR: Tesseract.js reads the text on your device. Google Cloud Vision reads the text through a Google API.
  • Folder watch: Petrify watches local folders or Google Drive folders. It converts new and changed files automatically.
  • Drag and drop: When you drop a handwriting file into the file explorer, Petrify creates the converted file at that location.
  • No duplicates: Petrify compares file and page hashes and skips files that it already converted.
