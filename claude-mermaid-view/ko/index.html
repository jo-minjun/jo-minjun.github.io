claude-mermaid-view

Claude Code mod

Claude 답변의 mermaid 블록을 터미널에서 텍스트 다이어그램으로 그리는 Claude Code mod다.

  • 문제: Claude가 그린 ASCII 다이어그램은 문서, PR, Slack으로 옮기면 정렬이 깨진다. mermaid 원문은 어디로든 옮길 수 있다. 하지만 터미널은 mermaid 원문을 코드로만 보여 준다.
  • 해결: 이 mod는 원문을 mermaid로 두고, 터미널 화면에서만 그림으로 그린다.

주요 기능

  • 지원 다이어그램: mod는 flowchart, sequence, class, ER, state, xychart 다이어그램을 그린다.
  • 폭 맞춤: 다이어그램이 터미널보다 넓으면, mod는 간격을 좁히거나 라벨을 줄바꿈해서 다시 그린다.
  • 다국어 정렬: mod는 한글, 중국어, 일본어, 이모지 라벨을 터미널에서 차지하는 실제 폭에 맞춰 정렬한다.
  • 원문 도구: 다이어그램마다 원문 보기, 원문 복사, mermaid.live에서 열기 버튼이 있다.
  • mermaid 지시: mod는 Claude에게 ASCII 그림 대신 mermaid 블록으로 그리라고 지시한다. 사용자는 /mermaid-prompt로 이 지시를 끄고 켠다.
  • 원문 보존: mod는 화면 표시만 바꾼다. 저장된 메시지에는 mermaid 원문이 그대로 남는다.
