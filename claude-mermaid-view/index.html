claude-mermaid-view

Claude Code mod

Claude 답변의 mermaid 코드 블록을 터미널 안에서 텍스트 다이어그램으로 그려 주는 Claude Code mod예요. mermaid 원문은 다이어그램 아래에 접혀 있어서 바로 복사하거나 mermaid.live에서 열 수 있어요.

A Claude Code mod that draws the mermaid code blocks in Claude's replies as text diagrams in the terminal. The mermaid source is folded under each diagram, ready to copy or open in mermaid.live.
