work-log

macOS 앱 · 에이전트 스킬 · macOS app · Agent skill

매일 한 일을 기록하는 도구예요. Claude Code나 Codex가 정해진 시각에 work-log 스킬을 실행해요. 스킬은 세션, 내가 보낸 Slack 메시지, 참여한 스레드의 결정 사항을 모아 월별 Markdown 로그에 써요. macOS 메뉴 막대 앱이 실행 일정과 실행 기록을 관리해요.

Records what you worked on each day. Claude Code or Codex runs the work-log skill on a schedule. The skill collects your sessions, your Slack messages and decisions from your threads into a monthly Markdown log. A macOS menu bar app manages the schedule and run history.
