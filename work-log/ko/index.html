work-log

macOS 앱 · 에이전트 스킬

에이전트가 매일 한 일을 모아 월간 업무 로그에 쓰는 macOS 도구다.

  • 문제: 데일리 스탠드업과 성과 평가에는 한 일의 근거가 필요하다. 이 근거는 Claude Code 세션과 Slack에 나뉘어 있다.
  • 해결: Claude Code나 Codex가 정해진 시각에 work-log 스킬을 실행한다. 스킬은 근거를 모아 프로젝트별 월간 Markdown 로그에 쓴다.

주요 기능

  • 수집 대상: 스킬은 Claude Code 세션, 내가 보낸 Slack 메시지와 DM, 내가 참여한 스레드의 결정과 합의를 모은다.
  • 프로젝트별 정리: 로그는 프로젝트마다 날짜별로 Claude 세션, Slack, 결정, 확인 필요 섹션을 둔다.
  • 새 프로젝트 제안: 관련 항목이 Other에 계속 쌓이면, 스킬은 새 프로젝트를 제안한다.
  • 메뉴 막대 앱: WorkLog.app은 실행 일정, 지금 실행, 실행 기록, 사용량을 관리한다.
  • 로그 언어: 스킬은 로그를 영어나 한국어로 쓴다.
