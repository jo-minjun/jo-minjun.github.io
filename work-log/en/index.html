work-log

macOS app · Agent skill

A macOS tool in which an agent collects what you did each day into a monthly work log.

  • Problem: Stand-ups and performance reviews need evidence of your work. This evidence is spread across Claude Code sessions and Slack.
  • Solution: Claude Code or Codex runs the work-log skill on a schedule. The skill collects the evidence and writes it into a monthly Markdown log by project.

Features

  • Sources: The skill collects your Claude Code sessions, your Slack messages and DMs, and decisions and agreements from your threads.
  • By project: For each project and date, the log has sections for Claude sessions, Slack, decisions and open items.
  • Project suggestions: When related items keep collecting in Other, the skill suggests a new project.
  • Menu bar app: WorkLog.app manages the schedule, Run now, the run history and usage.
  • Log language: The skill writes the log in English or Korean.
